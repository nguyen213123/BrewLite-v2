# Tài liệu sprint

Mỗi sprint tạo thư mục `sprint-01/`, `sprint-02/`, ... gồm:

- `planning.md`: mục tiêu, issue, người phụ trách, ước lượng và dependency.
- `review.md`: kết quả, demo và tiêu chí chưa đạt.
- `retrospective.md`: điều cần giữ, điều cần cải thiện và hành động sprint sau.

Phân công 6 người và thứ tự bàn giao nằm trong `../requirements/rebuild-plan.md`.
